Extract the fields below from one Iranian spare-part listing title.

Answer with exactly this JSON object:

{
  "fields": {
    "brand": string or null,
    "part_number": string or null,
    "part_type": string or null,
    "authenticity_claim": "genuine" | "oem" | "aftermarket" | "used" | "refurbished" or null,
    "pack_quantity": integer or null,
    "vehicle_hints": array of strings or null
  },
  "confidences": {
    "brand": number between 0 and 1,
    "part_number": number between 0 and 1,
    "part_type": number between 0 and 1,
    "authenticity_claim": number between 0 and 1,
    "pack_quantity": number between 0 and 1,
    "vehicle_hints": number between 0 and 1
  }
}

Field rules:

- brand — the manufacturer or the brand the seller names, written as it appears
  (ایساکو, سایپا یدک, بوش, کروز, والئو, تخت جمشید, ...). A shop name is not a
  brand. Null when the title names no brand.
- part_number — the manufacturer or OEM code exactly as printed, including its
  letters and separators. Never a phone number, never a price, never a vehicle
  model number such as 206, 405, 131 or EF7.
- part_type — what the part is, in Persian, as written.
- authenticity_claim — genuine (اصلی، اصل، ژنوین، اورجینال), oem (شرکتی، OEM),
  aftermarket (متفرقه، طرح، بازار، تایوانی، چینی), used (استوک، کارکرده،
  دست دوم), refurbished (بازسازی شده، تعمیری). Null when the title is silent.
- pack_quantity — how many units the package holds: جفت is 2, «بسته ۴ عددی» is
  4. Null unless the title states it.
- vehicle_hints — every vehicle the title mentions, as written, one entry each.
  Keep the trim with the model: «پژو 206 تیپ 5», not «206» and «تیپ 5».

A field the text does not state is null, and its confidence is 0.
